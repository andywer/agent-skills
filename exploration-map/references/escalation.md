# Optional delegation and review

Delegate a bounded branch when parallel work, separate context or independent judgment adds enough value to justify coordination. Follow the user's delegation preferences. Give the worker the actual question, relevant sources and a concrete result to return; do not require a custom packet, score changes or formal verdict.

For independent discovery, give the source and scenario without the suspected defect or intended remedy. Agreement between workers given the same leading brief is correlated, not independent evidence. Integrate supported findings into the inquiry's map, whether held in the parent's working context or a saved note, rather than pasting worker output wholesale.

Use an independent reviewer for unresolved judgment or integration risk that could materially change the decision, or when explicitly required. Multiple contributors alone do not create a review gate. Ask whether the claimed problem is real and in scope, and whether each proposed component or rule is reasonably necessary for the objective. No change or a simpler implementation may be sufficient.

Verify a repair against the defect and affected behavior. Obtain another independent review only if the remaining uncertainty warrants it or a real gate requires it; do not create a fixed repair-and-review cycle.
