# Skills Repository

This repository collects reusable Codex skill files.

Included skills:

- `instruction-editing`
- `intent-preserving-docs`
- `codex-goal-writing`
- `agent-managed-indexes`
- `complex-work`
- `working-state-refresh`
- `exploration-map`
- `paper-process-walkthrough`
- `failure-investigation`

Each skill lives in its own directory with a `SKILL.md` file. Install selected skills into the Codex skills directory configured for your environment.

`complex-work` replaces `environment-first`. The useful whole/detail reasoning from `recursive-zoom-exploration` is now part of `exploration-map`; it no longer has a separate entrypoint. `codex-goal-writing` uses the same directory and skill name in the repository and installed copies.
